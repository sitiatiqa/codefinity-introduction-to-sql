# 📊 Introduction to SQL

## 📌 Overview
This repository contains my learning materials and practice exercises for **Introduction to SQL**.  
The goal of this project is to understand the fundamentals of relational databases and how to query data using SQL.

This is part of my journey in building strong foundations in data analytics and reporting.

---

## 🧠 Topics Covered

- What is SQL?
- Understanding Databases & Tables
- SELECT statement
- WHERE clause
- ORDER BY
- LIMIT
- DISTINCT
- Basic Aggregate Functions:
  - COUNT()
  - SUM()
  - AVG()
  - MIN()
  - MAX()
- GROUP BY
- Basic filtering with AND / OR / IN / BETWEEN / LIKE

---

## 🎯 Learning Objectives

By completing this module, I am able to:

✔ Retrieve data from a database  
✔ Filter and sort data  
✔ Use aggregate functions  
✔ Group data for summary reporting  
✔ Write clean and readable SQL queries  

---


Strong fundamentals in SQL are essential before moving into advanced querying and data modeling.
